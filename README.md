# ABR | Диспетчер моделей

Плагин для **Топоматик Robur**. Расширенный менеджер моделей проекта: фильтрация по типу, управление видимостью, виртуальные группы, статусы, заметки и массовое переименование.

---

## Возможности

### Список моделей и фильтрация

- Полный список всех моделей открытого проекта
- **Фильтры по типу** — компактные кнопки-иконки для 18 типов моделей: ЦММ, Трасса, Дорога, Геология, Метро, Обустройство, ЖД, Путевое, Инженерные сети, Труба, Площадка, Картограммы, Земляные, DWG, Облако точек, Документы, Файл, Папка
- **Текстовый поиск** по имени модели
- Фильтрация по **статусам** (пользовательские метки)
- **Виртуальные группы** — организация моделей без изменения структуры проекта

### Управление видимостью

| Действие | Описание |
|----------|----------|
| Чекбоксы в списке | Открыть / закрыть отдельные модели |
| Перетаскивание по чекбоксам | Массовое выделение |
| **Открыть** | Открыть выбранные модели |
| **Закрыть** | Закрыть выбранные модели |
| **Изолировать** | Закрыть все, кроме выбранных |
| **Показать все** | Открыть все модели проекта |

### Прочее

- **Переключение активной модели** — двойной клик или кнопка «Активировать» (модель подсвечивается на плане)
- **Копировать путь** — скопировать путь к файлу модели в буфер обмена
- **Масштаб на модель** — перейти к границам модели на плане
- **Порядок отрисовки** — указан в списке
- **Заметки** — текстовые пометки к каждой модели, сохраняются в файл проекта
- **Статусы** — пользовательские цветные метки (например: готово, в работе, на проверке)
- **Сессионный лог** — история операций в текущем сеансе

### Массовое переименование

Диалог **«Переименовать...»** поддерживает шаблон с переменными:

| Переменная | Значение |
|------------|----------|
| `$N` | Порядковый номер в текущей выборке |
| `$NAME` | Исходное имя модели |
| `$TYPE` | Тип модели (road, dtm, survey и т.д.) |
| `$FOLDER` | Папка в дереве проекта |

Поддерживается **отмена** (Undo) последнего переименования.

## Сохранение состояния

Состояние менеджера (открытые модели, группы, статусы, заметки) сохраняется в файл `{имя_проекта}_modeldesk.json` рядом с файлом проекта и восстанавливается при следующем открытии.

## Установка

**Рекомендуется:** через [ABR | Библиотека модулей](https://github.com/Y-Abramov/robur-modules) — откройте «Модули → Библиотека модулей», найдите «Диспетчер моделей» и нажмите «Установить».

**Вручную:** скачать [`ModelDesk-1.0.0.tpm`](https://github.com/Y-Abramov/robur-modules/releases/tag/model-desk-v1.0.0) из Releases и установить через Topomatic Package Manager. Перезапустить Robur.

---

## Использование

После установки в ленте появится вкладка **Модели** с кнопкой «Диспетчер моделей». Диалог открывается поверх Robur и не блокирует работу с проектом.
